# KP EPI Data Quality Dashboard (DHIS2 Mock)
MBBS | Health Systems QA | UNICEF Portfolio Project

## Objective
Monitor Penta-3 immunization coverage across 6 BHUs in Peshawar using DHIS2 principles, flag facilities below UNICEF 80% target, and correlate data completeness with performance.

## Skills for UNICEF Health Officer NO-1
- HMIS/DHIS2 data analysis
- Program Monitoring & Evaluation
- Data Quality Audit (5000+ charts background applied to EPI)
- Python, Pandas, Matplotlib
- Low-coverage flagging & supportive supervision planning

## Findings
- 3/6 facilities below 80% target (RHC Chamkani 65%, THQ Mathra 71%, BHU Phandu 78%)
- Low completeness (70%) correlates with low coverage — suggests reporting issue vs real low coverage
